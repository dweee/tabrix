# Tabrix 能力层

## 目标

让 AI 助手清楚知道 Tabrix 能做什么，以及应该怎么最短路径完成任务。

## 典型能力

- 列出窗口与标签页
- 导航到目标页面
- 读取当前页面结构
- 识别页面对象、可操作目标和动作前后变化
- 提取正文内容
- 点击页面元素
- 填写表单
- 键鼠与滚动操作
- 页面截图
- 网络与控制台调试
- 在需要时使用受控 CDP / Chrome API 信号辅助判断加载、网络、frame、console、可见性和动作结果

## 最短成功路径

1. `get_windows_and_tabs`
2. `chrome_navigate`
3. `chrome_read_page`
4. `chrome_click_element` / `chrome_fill_or_select`
5. 重新读取页面或动作变化，验证结果

## 四库关系

- 对象库：记录当前和历史网页对象，帮助 AI 判断“这个页面有什么、能操作什么”。
- 记忆库：记录 AI 与 Tabrix 的工具调用、参数摘要、返回摘要和 AI 评价。
- 知识库：从对象库中异步沉淀网页结构和能力摘要。
- 经验库：从 AI 评价成功的记忆中异步沉淀可复用路径。

这些能力用于减少重复读页、减少盲点和减少 token 浪费，不用于保存原始私密页面数据。

## 使用原则

- 先结构化读取，再操作
- 先精确点击，再考虑坐标
- 先当前真实 Chrome，再考虑其它浏览器环境
- 先单步确认，再组合复杂动作

## 不建议做的事

- 不要把 shell 作为默认浏览器控制路径
- 不要只靠截图盲点页面
- 不要在页面变化后继续复用旧 `ref`
